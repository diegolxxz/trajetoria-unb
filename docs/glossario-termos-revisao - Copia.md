# Termos e siglas da UnB — rascunho para revisão

> Lista de trabalho para selecionar o que entrará no glossário. O site ainda não foi alterado.

## Como ler

Cada verbete tem um termo principal, seu significado e uma explicação curta. As categorias existem apenas neste arquivo. Códigos de setores repetidos em várias unidades aparecem uma vez; nomes alternativos ficam no mesmo verbete. As descrições marcadas “a confirmar” precisam de revisão antes da publicação. Localizações serão definidas depois.

**Total:** 139 termos para revisão.
